# Demo for consulting company

Закрытый учебный репозиторий для демонстрации работы финансиста с банковскими выписками. Все компании, счета, контрагенты, документы и суммы вымышлены.

## Сценарий

Финансист получает выписки Т‑Банка, Альфа‑Банка и СберБизнес, проверяет их, удаляет дубли, применяет правила конкретного проекта и выпускает готовый журнал с контрольным отчётом.

Базовая ветка `main` содержит правила, учебную выписку и шаблоны. Ветка `demo/process-bank-statement` показывает результат обработки. Из неё открыт Draft PR — его не нужно сливать, он служит демонстрацией процесса.

## Быстрый маршрут

1. Откройте `data/sample/inbox/bank_statement_august.csv` — учебный вход в форме Т‑Банка, все 28 полей сохранены.
2. Посмотрите описание трёх форм в `docs/02_source_schema.md` и правила в `docs/03_processing_rules.md`.
3. Запустите импорт с отдельным маппингом проекта:

   ```bash
   python -m bank_import data/sample/inbox/bank_statement_august.csv \
     --mapping config/projects/training_consulting.json \
     --output-dir build/import
   ```

4. Сравните `build/import/operations_ready.csv`, `exceptions.csv`, `duplicates.csv` и `control_report.json`.
5. Для другого проекта скопируйте `config/projects/_template.json`; правила учебного проекта не являются универсальными.

## Что демонстрируется

- автодетект и разбор форм Т‑Банка, Альфа‑Банка и СберБизнес;
- сохранение исходных полей каждого банка в raw-слое;
- стабильный идентификатор строки источника и операции;
- защита от повторной загрузки;
- различение поступлений, списаний и внутренних переводов;
- отдельный JSON-маппинг статей ДДС, ОПиУ и балансовых счетов для каждого проекта;
- отдельная очередь исключений;
- сверка количества строк и денежных оборотов.

## Код и документация

- `bank_import/` — парсеры, нормализация, маппинг, контроли и загрузка в Google Sheets;
- `config/projects/` — правила конкретных проектов;
- `docs/07_bank_formats.md` — координаты и особенности банковских форм;
- `docs/08_project_mapping.md` — устройство расширяемого маппинга;
- `docs/09_run_import.md` — запуск, результаты и загрузка журнала;
- `tests/` — минимальные тестовые книги, создаваемые без реальных реквизитов.

Реальные выписки и файлы учётных данных нельзя добавлять в Git. Для локальных файлов предназначена игнорируемая папка `data/private/`.
