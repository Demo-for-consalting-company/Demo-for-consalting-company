# Demo for consulting company

Закрытый учебный репозиторий для демонстрации работы финансиста с банковской выпиской. Все компании, счета, контрагенты, документы и суммы вымышлены.

## Сценарий

Финансист ООО «Атлас» получает выписку в форме Т‑Банка, проверяет её, удаляет дубли, распределяет операции по статьям и проектам «Орион» и «Вектор», затем выпускает готовый журнал и контрольный отчёт.

Базовая ветка `main` содержит правила, учебную выписку и шаблоны. Ветка `demo/process-bank-statement` показывает результат обработки. Из неё открыт Draft PR — его не нужно сливать, он служит демонстрацией процесса.

## Быстрый маршрут

1. Откройте `data/sample/inbox/bank_statement_august.csv` — это учебный вход в исходной форме Т‑Банка, все 28 полей сохранены.
2. Прочитайте `docs/03_processing_rules.md` и `docs/04_mapping_and_exceptions.md`.
3. Переключитесь на ветку `demo/process-bank-statement`.
4. Сравните `output/operations_ready.csv`, `output/exceptions.csv` и `output/control_report.md`.
5. Откройте Draft PR, чтобы увидеть изменения как результат работы финансиста.

## Что демонстрируется

- сохранение исходной банковской формы без потери полей;
- стабильный идентификатор строки источника и операции;
- защита от повторной загрузки;
- различение поступлений, списаний и внутренних переводов;
- маппинг статей ДДС, ОПиУ и балансовых счетов;
- отдельная очередь исключений;
- сверка количества строк и денежных оборотов.

Реальные выписки нельзя добавлять в Git. Для локальных файлов предназначена игнорируемая папка `data/private/`.
