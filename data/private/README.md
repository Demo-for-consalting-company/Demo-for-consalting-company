# Локальные данные клиента

Эта папка предназначена для временной работы с реальными файлами только на компьютере сотрудника и только в согласованных границах доступа. Её содержимое, кроме этой инструкции, исключено из Git.

Не добавляйте в репозиторий:

- реальные банковские выписки;
- персональные данные;
- конфиденциальные договоры и письма;
- пароли, токены и ключи;
- файлы сервисных аккаунтов;
- ссылки, открывающие доступ без дополнительной авторизации.

После завершения работы храните или удаляйте локальные копии по правилам безопасности компании. Сам факт наличия файла здесь не даёт агенту разрешение отправлять его, изменять исходник или публиковать содержимое.
