# Обезличенные учебные данные

Реальные данные клиента в эту папку добавлять нельзя.

В папке `основной_сценарий` находятся три независимые выписки одной компании:

- Т‑Банк — 8 операций и все 28 исходных полей формы;
- Альфа‑Банк — 8 операций в структуре выписки Альфа‑Банка;
- СберБизнес — 8 операций в структуре СберБизнес.

Из 24 операций 23 соответствуют существующим правилам. Оплата лицензии платформы информационной безопасности намеренно не описана в `config/projects/atlas.json` и должна попасть в список «Требует решения».

Папка `дополнительно` содержит точную копию выписки Т‑Банка под другим именем. Она нужна только для демонстрации дедупликации: при загрузке вместе с основным сценарием система должна найти 8 повторов.

Внутри файлов нет пометок «учебный» или «обезличенный»: они выглядят как обычные выписки, но все значения вымышлены.
