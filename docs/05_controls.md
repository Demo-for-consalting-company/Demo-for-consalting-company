# Контроли

## Структурные

- присутствуют все 28 исходных полей;
- дата, направление и сумма распознаны;
- заполнен ровно один из столбцов `Дебет` и `Кредит`;
- валюта поддерживается;
- каждая исходная строка получила `source_row_id`.

## Дедупликация

- входящих строк: 21;
- уникальных операций: 20;
- принятых операций: 18;
- исключений: 2;
- дублей: 1;
- контроль количества: `21 = 18 + 2 + 1`.

## Денежная сверка по уникальным операциям

- входящий остаток: 500 000 RUB;
- поступления: 3 825 000 RUB;
- списания: 2 029 845 RUB;
- исходящий остаток: 2 295 155 RUB;
- формула: `500 000 + 3 825 000 − 2 029 845 = 2 295 155`.

Дубль не участвует в денежной сверке. Исключения участвуют, потому что это реальные для учебного кейса движения денег, даже если их аналитика пока не определена.
