# Схема исходной выписки

Учебный CSV повторяет 28 полей формы Т‑Банка в исходном порядке:

1. Номер счёта
2. Тип операции
3. Дата проведения
4. Номер документа
5. Валюта операции
6. Сумма в валюте счёта
7. Валюта счёта
8. Описание операции
9. Назначение платежа
10. Счет плательщика
11. ИНН плательщика
12. КПП плательщика
13. Наименование плательщика
14. БИК банка плательщика
15. Корр. счет плательщика
16. Счет получателя
17. Договор получателя
18. ИНН получателя
19. КПП получателя
20. Наименование получателя
21. БИК банка получателя
22. Корр. счет получателя
23. Счет контрагента
24. ИНН контрагента
25. Наименование контрагента
26. БИК банка контрагента
27. Дебет
28. Кредит

Для типа `Дебет` заполнено поле `Дебет`, для типа `Кредит` — поле `Кредит`. Денежный код `643` нормализуется в `RUB`, но исходное значение сохраняется.

Технические поля создаются при обработке:

- `source_row_id` — позиционный идентификатор строки конкретного файла;
- `operation_id` — стабильный ключ из счёта, даты, номера документа, направления и суммы;
- `money_in` и `money_out` — нормализованные денежные потоки;
- `article`, `project`, `cash_flow_line`, `pnl_line`, `balance_account` — результаты маппинга.
