# Учебный кейс

ООО «Атлас» ведёт два консультационных проекта: «Орион» и «Вектор». В августе 2026 года финансист получает банковскую выписку и должен подготовить данные для управленческого учёта.

В выборке есть обычные поступления и списания, внутренний перевод, кредитные операции, две разные операции с одинаковой датой и суммой, один настоящий дубль и две строки, требующие ручного решения.

Ожидаемый результат — чистый журнал операций, очередь исключений и контрольный отчёт. Исходная форма банка должна оставаться неизменной, чтобы тот же файл можно было использовать для разработки и тестирования Excel-парсера.
