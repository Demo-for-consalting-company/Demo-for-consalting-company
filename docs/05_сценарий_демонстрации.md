# Сценарий демонстрации

1. Открыть корневой `README.md` и показать маршрут без технических терминов.
2. Открыть папку `data/sample/основной_сценарий` и показать три исходные формы банков.
3. Загрузить все три файла в чат вместе с `prompts/обработать_выписки.md`.
4. Показать итог: 24 строки, 23 распределены, 1 требует решения, дублей нет.
5. Открыть неизвестную операцию по информационной безопасности и объяснить, почему система её не угадала.
6. Показать `config/projects/atlas.json`: это правила только компании «Атлас», а не общая таблица для всех клиентов.
7. Согласовать новую статью и использовать `prompts/классифицировать_новую_статью.md`.
8. Повторить обработку и получить 24 готовые строки при неизменных денежных суммах.
9. При необходимости добавить файл из папки `дополнительно` и показать 8 дублей.
10. Открыть `output/sample/контроль.md` и объяснить, что это сверка импорта, а не отдельная форма отчётности.
11. Показать Draft PR как историю изменений; слияние для демонстрации не требуется.
