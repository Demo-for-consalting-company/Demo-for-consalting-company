# Сценарий демонстрации

1. Показать `main` и объяснить, что в репозитории нет реальных данных.
2. Открыть исходный CSV и обратить внимание на неизменённые 28 полей Т‑Банка.
3. Найти две строки с одинаковой датой и суммой, но разными документами — они не являются дублями.
4. Найти повтор строки `DOC-100003` — это настоящий дубль.
5. Переключиться на `demo/process-bank-statement`.
6. Показать готовый журнал: 18 строк с маппингом ДДС, ОПиУ и баланса.
7. Показать два исключения и объяснить, почему их нельзя распределить автоматически.
8. Открыть контрольный отчёт и подтвердить количество строк и денежную сверку.
9. Открыть Draft PR как аудиторский след работы, не выполнять merge.
