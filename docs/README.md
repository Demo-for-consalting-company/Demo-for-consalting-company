# Документация

Здесь сохранены дополнительные материалы по учебному примеру обработки банковских выписок. Универсальная модель финансовой работы начинается в [корневом README](../README.md), а готовый результат можно посмотреть в [учебной финансовой таблице](../output/sample/Учебная_финансовая_таблица.xlsx).

Начните с первого файла и переходите дальше только если нужна дополнительная детализация:

1. [Как работает обработка](01_как_работает_обработка.md) — роли файлов и этапы процесса.
2. [Форматы банков](02_форматы_банков.md) — какие поля читаются у Т‑Банка, Альфа‑Банка и СберБизнес.
3. [Правила проекта «Атлас»](03_правила_проекта_атлас.md) — как назначаются статьи ДДС, ОПиУ, проекта и баланса.
4. [Контроль и исключения](04_контроль_и_исключения.md) — что система сверяет и что делать с новой статьёй.
5. [Сценарий демонстрации](05_сценарий_демонстрации.md) — последовательность показа на встрече.
6. [Технический запуск](06_технический_запуск.md) — команды, файлы результата и Google Sheets.
7. [Инструкция для финансовой команды](08_инструкция_по_работе_финансовой_команды.md) — первые шаги, ежедневная работа, задания агенту, закрытие месяца и контроль результата.
