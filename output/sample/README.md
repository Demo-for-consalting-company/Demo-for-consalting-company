# Обезличенный пример результата

Эта папка нужна только для просмотра. Она сохраняет существующий учебный пример и показывает результат обработки трёх файлов из `data/sample/основной_сценарий`:

- `готовые_операции.csv` — 23 операции, для которых нашлось правило;
- `требует_решения.csv` — одна операция по информационной безопасности;
- `контроль.md` — понятная сверка количества строк и денежных оборотов.

CSV сохраняют технические поля для аудита. В Google Sheets эти столбцы располагаются справа и могут быть скрыты; обычный пользователь работает с датой, поступлением, списанием, счётом, статьями, проектом, контрагентом, назначением, Дт и Кт.

Актуальный локальный запуск пишет служебные файлы в игнорируемую папку `build/latest`, поэтому эта папка не засоряется при каждом тесте.
