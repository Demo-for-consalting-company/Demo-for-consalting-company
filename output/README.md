# Результаты работы

Здесь сохраняются подготовленные для проверки результаты: контрольные отчёты, проекты управленческих материалов, сценарии и пакеты передачи клиента.

- Не сохраняйте здесь реальные банковские выписки, персональные данные, договоры, пароли, токены или ключи.
- Рабочие результаты с чувствительными данными храните в согласованном защищённом месте, а не в Git.
- В имени файла указывайте клиента, период и назначение, например `клиент_2026-08_контрольный_отчёт.md`.
- Внутри результата указывайте дату актуальности, источники, статус проверок и ограничения.
- Не обозначайте проект отчёта как окончательный до решения финансиста.

Папка [sample](sample) содержит сохранённый обезличенный результат учебной обработки банковских выписок и автономную Excel-копию [основного примера в Google Таблицах](https://docs.google.com/spreadsheets/d/1116aAKX8rnDXxYKIA0akJJtDpxi7U9Jju2YB2Xxh1nA/edit?gid=2026091401#gid=2026091401). Эти материалы нужны для обучения и сравнения и не являются отчётностью реального клиента.

Папка [pdf](pdf) содержит готовые материалы для знакомства и обучения финансовой команды. Их исходные правила и рабочие формы остаются в Markdown-файлах репозитория.
