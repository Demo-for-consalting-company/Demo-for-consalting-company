# Правила проектов

Здесь лежит по одному файлу правил на каждого клиента или проект.

- `atlas.json` — действующие правила компании «Атлас» для текущего примера.
- `_template.json` — пустая заготовка. Она не участвует в обработке и нужна только как форма для нового клиента.

Чтобы подключить нового клиента, скопируйте `_template.json`, назовите копию по проекту, заполните правила и передайте этот файл параметром `--mapping`. Банковские парсеры при этом менять не нужно.

Правила проверяются сверху вниз: сначала частные, затем общие. Если ни одно правило не подошло, операция остаётся без статьи и уходит в список «Требует решения». После решения финансиста добавляется новое узкое правило, которое можно проверить и воспроизвести при следующем импорте.
